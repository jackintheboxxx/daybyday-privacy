요약

데이터를 수신할 서버가 없습니다. 모든 기록은 휴대폰에 저장됩니다.

  • 일기, 사진, 체중, 증상, 검진 날짜는 휴대폰에 저장됩니다.
  • 서버가 없으며 데이터를 수집하거나 업로드하지 않고 볼 수도 없습니다.
  • 계정, 로그인, 광고 추적, 제3자 분석 도구가 없습니다.
  • 사진 접근을 허용하면 직접 백업할 수 있도록 휴대폰의 DaybyDay 앨범에도 사진을 복사합니다.
  • 설정에서 언제든 데이터를 내보내거나 삭제할 수 있습니다.
  • 앱을 삭제하면 앱 내부 기록이 삭제됩니다. 내보낸 파일, 사진 앨범 또는 iCloud 백업의 사본은 남을 수 있습니다.

1. 요약

DaybyDay는 개인정보를 수집하지 않습니다. 데이터를 수신할 서버도 없습니다.

기록은 휴대폰 내부에 저장됩니다. 본인과 잠금 해제된 휴대폰에 접근할 수 있는 사람이 볼 수 있습니다.

2. 수집하는 정보

이름, 이메일, 전화번호, 위치, 기기 식별자, 이용 내역, 오류 보고서를 포함한 데이터를 수집하지 않습니다.

앱에는 제3자 분석 도구, Google Analytics, Firebase, Facebook SDK 또는 광고 추적 SDK가 없습니다.

계정 시스템이 없으므로 로그인할 필요가 없습니다.

3. 데이터 저장 위치

모든 데이터는 휴대폰에 저장됩니다:

  • 일기, 체중, 증상, 기분, 수유, 검진 날짜 등의 문자 기록은 앱의 내부 저장 공간에 보관됩니다.
  • 사진은 앱의 전용 폴더에 복사됩니다. 사진 접근을 허용하면 휴대폰의 DaybyDay 앨범에도 저장됩니다.
  • iPhone에서 iCloud 백업을 켜면 이 기록도 본인의 백업에 포함됩니다. 해당 백업은 사용자와 Apple 사이에서 관리되며 저희는 접근할 수 없습니다.

4. 건강 데이터

앱은 임신, 생리, 출산 후 건강 관련 정보를 기록합니다. 민감한 정보이므로 저희는 접근하지 않습니다.

앱은 기록을 기기 외부, 서버 또는 제3자에게 자동 전송하지 않습니다. 내보내기와 기기 백업은 사용자가 관리합니다.

앱은 iPhone의 건강(HealthKit) 데이터를 읽지 않습니다.

5. 알림

모든 알림은 서버 없이 휴대폰이 예약하고 보내는 로컬 알림입니다. 저희는 설정한 알림이나 수신 여부를 알 수 없습니다.

앱 설정에서 알림 종류별로 끄거나 시스템 설정에서 알림 권한을 해제할 수 있습니다.

6. 사용자가 할 수 있는 일

  • 내보내기: 설정 → 데이터 백업 → 모든 데이터 내보내기에서 JSON 파일을 만듭니다. 저장 위치는 직접 선택합니다.
  • 복원: 이전에 내보낸 파일에서 복원할 수 있습니다.
  • 삭제: 설정 → 초기화를 이용하거나 앱을 삭제하세요. 앱을 삭제하면 앱 내부 데이터도 삭제됩니다.
  • 내보낸 파일, 휴대폰 앨범의 사진, iCloud 백업은 앱을 삭제해도 남습니다. 별도로 관리해야 합니다.

7. 아동

앱은 성인 보호자용이며 아기의 생일, 체중, 사진 등을 기록할 수 있습니다. 이 정보도 기기에 저장되며 저희는 수집하지 않습니다.

아동을 대상으로 직접 홍보하지 않으며 광고를 표시하지 않습니다.

8. 콘텐츠의 성격

임신, 육아, 식사, 산후 전통 관습 및 건강 콘텐츠는 공개 정보와 중국 문화권의 관습을 정리한 참고 정보입니다. 전문적인 조언이 아니며 의료진의 판단을 대신하지 않습니다.

출산 예정일, 생리일, 배란일 예측은 입력한 기록에 근거한 추정입니다. 정확성을 보장하지 않으며 피임이나 임신의 판단 근거로 삼지 마세요.

평소와 다른 몸의 변화가 있으면 의료진에게 직접 연락하세요.

9. 방침 업데이트

향후 휴대폰 간 기록 공유처럼 데이터 전송이 필요한 기능을 추가하면 출시 전에 방침을 업데이트하고 앱에서 다시 동의를 구합니다. 동의 없이 데이터를 전송하지 않습니다.

10. 문의

개인정보 관련 문의는 App Store 또는 Google Play에 기재된 지원 연락처로 연락해 주세요.

앱의 의견 기록 기능은 내용을 기기에만 저장하며 저희에게 전송하지 않습니다. 개발자는 이를 통해 메시지를 받지 못합니다.

이용약관 주요 내용

  • DaybyDay의 기본 기록 기능은 무료이며 일부 고급 콘텐츠는 구독이 필요할 수 있습니다. 앱은 명시적 또는 묵시적 보증 없이 있는 그대로 제공됩니다.
  • 앱 콘텐츠는 일반 참고 정보이며 의료 조언이 아닙니다. 앱의 내용만으로 의료 결정을 내리지 않는 데 동의합니다.
  • 데이터 백업은 사용자의 책임입니다. 저희는 사본을 보유하지 않으므로 대신 복원할 수 없습니다.
